# Demo script (owner: C)

Two minutes. Rehearse with `PILLWISE_OFFLINE=1`.

1. Hook (15 s): many older adults take medicines from several doctors; nobody sees the whole list. Hold up the bottles.
2. Capture (30 s): photograph 3 bottles live; the list appears; correct one field to show the confirm step.
3. Red flag (30 s): warfarin + ibuprofen, DDInter advice and the exact FDA label sentence.
4. Simplify (20 s): switch to Spanish or Chinese; show reading grade and drift check.
5. Trust (15 s): open the sources panel / audit log. Flash the clinic view if built.
6. Close (10 s): governed data in, explained and sourced answers out.
